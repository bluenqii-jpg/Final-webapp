# เที่ยวสวนสัตว์นครปฐม · Web App (Final Project)

เว็บแอปสำหรับผู้เยี่ยมชมสวนสัตว์นครปฐม ผู้ใช้หมุนดูแผนที่ 3 มิติขนาดเล็กของสวนสัตว์ได้ แตะที่กรงเพื่อดูข้อมูลสัตว์แต่ละชนิด อาหารที่ให้ได้และไม่ควรให้ และดูตำแหน่งทางเข้า–ทางออก ห้องน้ำ และจุดบริการได้ แอปยังย้ำเตือนเรื่องการให้อาหารสัตว์และการรักษาความสะอาดตลอดการเที่ยวชม

## ฟีเจอร์หลัก

- **แผนที่ 3 มิติ** — แผนที่จำลองสวนสัตว์แบบโมเดลจิ๋ว หมุนดูได้ 4 มุมมอง
- **Pop-up ข้อมูลสัตว์** — แตะกรงเพื่อดูชื่อ ถิ่นอาศัย และเรื่องน่ารู้ของสัตว์
- **อาหารที่ให้ได้ / ห้ามให้** — แยกเป็นกรอบสีเขียวและสีแดงให้เห็นชัด
- **จุดบริการ** — ทางเข้า ทางออก ห้องน้ำ ถังขยะ และร้านขายอาหารสัตว์
- **ข้อห้ามและการรักษาความสะอาด** — แอปย้ำเตือนก่อนเข้าชมและที่หน้ากรง

## User Flow

1. สแกน QR ที่ทางเข้าหรือที่ป้ายหน้ากรง
2. อ่านกฎก่อนเข้าชม แล้วกดรับทราบ
3. หมุนแผนที่ 3 มิติ แล้วแตะกรงที่สนใจ
4. ดู pop-up ข้อมูลสัตว์และอาหารที่ให้ได้
5. นำทางไปกรงถัดไป ห้องน้ำ หรือทางออก

## Design

- **Mood & Tone:** อบอุ่น เป็นมิตร ใกล้ชิดธรรมชาติ แผนที่ออกแบบเป็นโมเดลจิ๋ว
- **ฟอนต์:** Mitr (หัวข้อ) · Sarabun (เนื้อหา)
- **สีหลัก:** เขียวป่า `#3F5B36` · มะกอก `#7C9A4E` · ครีม `#F4EEDC` · ส้มแดด `#E08A3C` · ข้อห้าม `#B8432F`

> ข้อมูลอาหารของสัตว์แต่ละชนิดในงานนี้ใช้เพื่อแสดงแนวคิด ข้อมูลจริงควรผ่านการตรวจสอบจากสัตวแพทย์ของสวนสัตว์
